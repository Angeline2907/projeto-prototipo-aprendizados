# 🚀 Hora do Desafio: Aprendizados do Protótipo

Este repositório foi criado para registrar as reflexões, feedbacks e aprendizados obtidos após a apresentação e o teste do protótipo do nosso aplicativo com outros usuários.

---

## 💡 Principais Aprendizados (Validação e Testes)

Ao observar outras pessoas interagindo com a nossa solução, identificamos os seguintes pontos críticos:

### 1. Primeiro Aprendizado Importante
*   **O que observamos:** [Exemplo: Os usuários entenderam muito rápido como fazer o cadastro, achando o fluxo intuitivo, mas tiveram dificuldades para encontrar o botão de configurações.]
*   **Impacto no projeto:** [Exemplo: Precisamos mudar a posição do ícone de configurações para o menu principal para melhorar a acessibilidade.]

### 2. Segundo Aprendizado Importante
*   **O que observamos:** [Exemplo: A funcionalidade de histórico de atividades foi apontada como a mais útil do app, gerando mais interesse do que o esperado.]
*   **Impacto no projeto:** [Exemplo: Vamos dar mais destaque visual a essa ferramenta na tela inicial.]
